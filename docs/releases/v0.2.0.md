# AtracDEnc-AAL v0.2.0

## 中文

AtracDEnc-AAL 是**基于 [AtracDEnc](https://github.com/dcherednik/atracdenc) 项目开发的 AAL 编码器**。本版提供 Windows x64 与 macOS 通用命令行、C ABI、完整源码，以及简易 Windows 测试界面。

- AAL3：132 kbps。
- AALP：48 / 64 / 96 / 128 / 160 / 192 / 256 / 320 / 352 kbps。
- 默认：AALP / ATRAC3plus 352 kbps。
- 输入：44.1 kHz、16-bit、双声道整数 PCM WAV。
- 无需安装 Sony SMLE、TraConv、Sony DLL、FFmpeg 或 .NET。
- 中英文 README、上游来源与许可证、构建文档、集成示例、GitHub CI 和 4583 包离线夹具齐备。
- `AtracDEnc-AAL-GUI.exe` 明确标注为简易测试图形界面，按系统显示语言自适应中英文，也可使用 `--lang zh` / `--lang en`。

当前名称由已经验证的 Independent AAL 0.2 基线整理而来；CLI 为 `atracdenc-aal`，Windows GUI 为 `AtracDEnc-AAL-GUI.exe`。现有 `aal_*` C ABI 与头文件名保留。更名版的离线检查和基线 OMA 输出对照见源码中的 `validation/release-verification.json`。

```powershell
.\atracdenc-aal.exe --profile aalp-352 "input.wav" "output.oma"
```

**验证范围：** 增强层的 4583 个已记录官方包逐字节一致；基线完整文件的十档测试经 Sony 解码后 PCM 精确还原。有损核心来自 AtracDEnc 的兼容实现，完整文件字节和压缩体积不等同于 Sony 官方。Mac 二进制已交叉编译，真实 Mac 和 NW-X1050 / X1060 硬件执行仍待验证。GUI 由用户自行交互测试。

发行附件包括 Windows x64、macOS universal 和完整源码 ZIP，以及 `SHA256SUMS.txt`。程序和完整对应源码一起提供；许可证为 LGPL-2.1-or-later，保留 AtracDEnc 及依赖归属。

## English

AtracDEnc-AAL is an **AAL encoder built on [AtracDEnc](https://github.com/dcherednik/atracdenc)**. This release includes a Windows x64 CLI, macOS universal CLI, C ABI, complete source and a small Windows test GUI.

- AAL3: 132 kbps.
- AALP: 48 / 64 / 96 / 128 / 160 / 192 / 256 / 320 / 352 kbps.
- Default: AALP / ATRAC3plus 352 kbps.
- Input: 44.1 kHz, 16-bit, stereo integer PCM WAV.
- No Sony SMLE, TraConv, Sony DLL, FFmpeg or .NET runtime installation.
- Bilingual README, upstream/license information, build and integration guides, GitHub CI and 4,583 offline enhancement fixtures.
- `AtracDEnc-AAL-GUI.exe` is labeled as a simple test GUI, adapts to Chinese/English display languages and supports `--lang zh` / `--lang en`.

The project is prepared from the validated Independent AAL 0.2 baseline. The CLI is `atracdenc-aal`; the Windows GUI is `AtracDEnc-AAL-GUI.exe`. Existing `aal_*` C ABI identifiers and the header name are retained. Current offline checks and baseline OMA comparisons are recorded in `validation/release-verification.json` in the source.

```bash
./atracdenc-aal --profile aalp-352 "input.wav" "output.oma"
```

**Validation scope:** The 4,583 recorded official enhancement packets match byte-for-byte. Baseline full-file tests across all ten profiles reconstruct exact PCM through Sony's decoder. The lossy core is AtracDEnc's compatible implementation; complete bytes and compression sizes differ from Sony. Mac binaries are cross-compiled; native Mac execution and physical NW-X1050 / X1060 compatibility remain unverified. GUI interaction testing is left to the user.

Assets include Windows x64, macOS universal and complete-source ZIP files plus `SHA256SUMS.txt`. Executables and complete corresponding source are supplied together under LGPL-2.1-or-later, with AtracDEnc and dependency attribution retained.
