# AtracDEnc-AAL v0.3.0 — 独立 AAL 解码 / Independent AAL decoding

**实验版 / Pre-release**

AtracDEnc-AAL 是基于 [AtracDEnc](https://github.com/dcherednik/atracdenc) 开发的 AAL 编解码器，运行时无需 Sony SMLE、TraConv、Sony DLL 或 FFmpeg。

An AAL encoder/decoder based on AtracDEnc, with no Sony SMLE, TraConv, Sony DLL or FFmpeg runtime requirement.

- 新增 `--decode` / `-d`：未加密 AAL OMA/AA3 → 44.1 kHz / 16-bit / stereo PCM WAV；自动识别 AAL3-132 与九档 AALP。New standalone decoding for all ten supported profiles.
- C API 新增 `aal_decode_cd16`、`aal_pcm_buffer` 和 `aal_pcm_free`；编码 ABI 保持不变。New decoder API preserves the encoder ABI.
- `AtracDEnc-AAL-GUI.exe` 仍标注为简易测试图形界面，自动中英文，按输入类型进行 WAV→AAL 或 AAL→WAV。The simple bilingual Windows test GUI now converts in both directions.
- 469 例 / 18,633,240 个 int16 样本及长度均与原始 PCM 和实际 Sony 解码一致。公开离线解码夹具为 38 例 / 973,416 个 int16 样本。Exact full-file PCM and length validation against Sony; public fixtures require no Sony software.
- Windows x64 本地六项离线检查全部通过；macOS arm64 / Intel 已交叉编译。Native CI status is recorded separately when available.

```text
atracdenc-aal --decode input.oma output.wav
atracdenc-aal --profile aalp-352 input.wav output.oma
```

输入与输出 PCM 各自限 1 GiB。解码目前限未加密 44.1 kHz / 16-bit / 双声道 AAL，不含普通有损 ATRAC、DRM、多声道或流式 seek API。原编码器的有损核心决策仍不同于 Sony，完整编码字节和压缩体积仍可能不同。特定预构建 Mac universal 文件未在真实 Mac 上直接执行；Walkman 硬件播放尚未测试。GUI 交互由用户测试。

Input and decoded PCM are each limited to 1 GiB. Decoding currently covers unencrypted CD-format stereo AAL, excluding ordinary lossy ATRAC, DRM, multichannel and streaming seek APIs. Encoder core decisions, complete encoded bytes and compression sizes can still differ from Sony. The specific prebuilt Mac universal binary has not been directly run on a Mac, and physical Walkman playback remains untested. GUI interaction testing is left to the user.

附件 / Assets: Windows x64 CLI + simple test GUI + static library; macOS universal CLI + arm64/Intel static libraries; full source; SHA256SUMS.txt.
