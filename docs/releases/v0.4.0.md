# AtracDEnc-AAL 0.4.0

基于 AtracDEnc 开发的独立 AAL 编解码器，现提供 **Windows / macOS 双平台小型简易测试文件转换器**，以及 CLI、C API 和完整源码。保留实验版标识。

An independent AAL codec built on AtracDEnc, now with **small native Windows/macOS test file converters**, plus CLI, C API and complete source. This remains an experimental release.

## 下载与使用 / Downloads and use

- **Windows x64 ZIP**：解压后打开 `AtracDEnc-AAL-GUI.exe`；同目录保留 CLI。Extract and open the simple test GUI; the CLI is included.
- **macOS universal ZIP**：打开 `AtracDEnc-AAL-GUI.app`；支持 Apple Silicon / Intel，最低 macOS 11。Native AppKit simple test GUI for Apple Silicon and Intel, macOS 11+; includes the universal CLI.
- **Source ZIP**：完整生产源码、上游归属、许可证、技术资料、测试及离线夹具。Complete production source, attribution, licenses, technical notes, tests and offline fixtures.
- **SHA256SUMS.txt**：三个发行 ZIP 的摘要。Checksums for the three ZIPs.
- **RELEASE-VALIDATION.json**：实际原生构建、无窗口执行、通用附件检查和源码提交记录。Observed native builds, headless execution, universal-asset checks and exact source commit.

两平台 GUI 均为**简易测试图形界面**，按系统首选语言自动使用中文或英文；无需 Sony、FFmpeg、.NET 或其他音频工具。提供队列、核心选择、输出目录、进度、取消、自检和防覆盖命名。macOS `.app` 仅 ad-hoc 签名，没有 Developer ID 签名或公证。

Both are **simple test GUIs** with automatic Chinese/English selection, directly linked to the independent codec. No Sony component, FFmpeg, .NET or external audio tool is needed. Features include a queue, profile selection, output folder, progress, cancellation, self-test and collision-safe names. The macOS app is ad-hoc signed, without Developer ID signing or notarization.

## 必须满足的输入规格 / Required inputs

**编码：44,100 Hz / signed 16-bit / 双声道整数 PCM RIFF/WAV（format tag 1），文件 ≤1 GiB。** 24/32-bit、浮点、单/多声道及其他采样率直接拒绝；无自动重采样或位深转换。

**Encode: 44,100 Hz / signed 16-bit / stereo integer PCM RIFF/WAV (format tag 1), file up to 1 GiB.** 24/32-bit, float, mono/multichannel and other-rate input is rejected; no automatic resampling or bit-depth conversion.

**解码：未加密 AAL3/AALP OMA/AA3，本项目十档配置；输入和输出 PCM 各 ≤1 GiB。** 输出为 44.1 kHz / 16-bit / 双声道 WAV。普通有损 ATRAC、DRM、Standard、MP3/FLAC 等直接输入不支持。详见 [输入规格](../INPUT-FORMATS.md)。

**Decode: unencrypted AAL3/AALP OMA/AA3 in the ten supported profiles; input and output PCM each up to 1 GiB.** Output is CD-format stereo WAV. Ordinary lossy ATRAC, DRM, Standard and direct MP3/FLAC input are unsupported. See [input requirements](../INPUT-FORMATS.md).

## 模式与证据 / Modes and evidence

**仅支持 High-Speed Transfer 双层 AAL。Standard 未实现，目前没有可核验的实际证据证明 RFC 定义的 Standard 模式曾在真实产品或服务中应用。** 新增两种模式的双语综述、分模式技术资料和来源，区分规范、产品支持、广播实验及未知项。AAL for Broadcasting 的实验记录不构成 RFC Standard 已落地的证明。见 [AAL 模式与依据](../AAL-MODES.md)。

**High-Speed Transfer two-layer AAL only. Standard is not implemented; no verified actual evidence currently establishes product/service use of the RFC-defined Standard mode.** New bilingual technical notes distinguish specifications, product claims, broadcast experiments and unknowns. AAL for Broadcasting trial records do not establish Standard deployment. See [modes and evidence](../AAL-MODES.md).

## 验证范围 / Validation scope

发布流程要求 Windows x64、macOS arm64 和 macOS Intel 原生构建及全部八项无窗口检查通过，并在 macOS 上合并通用附件、核对原生包摘要和双架构、验证 ad-hoc 签名，再执行最终通用 CLI/GUI 的 Apple Silicon 无窗口诊断。具体结果以附件 `RELEASE-VALIDATION.json` 和对应 Actions 运行记录为准。

Publication requires all eight headless checks on native Windows x64, macOS arm64 and macOS Intel, followed by universal assembly, hash/architecture/signature verification and final universal CLI/GUI headless execution on Apple Silicon. The attached validation record and linked Actions run describe the actual results.

编解码算法及 C ABI 不变；仍不保证完整文件字节或压缩体积与 Sony 一致。GUI 的视觉显示和交互由用户测试；NW-X1050/X1060 等物理 Walkman 播放、跳转和传输未验证。

Codec algorithms and C ABI are unchanged. Complete bytes and compression size are not guaranteed equal to Sony. GUI appearance/interaction is tested by the user; physical Walkman playback, seeking and transfer remain unverified.
